# RecipeHub

A full-stack recipe discovery web app where users can browse, search, save, and explore featured and popular recipes from around the world. Built to make finding and sharing great recipes simple, fast, and enjoyable.

🔗 **Live:** [recipes-hub-teal.vercel.app](https://recipes-hub-teal.vercel.app/)

## Tech Stack

- **Frontend:** Next.js, React, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Auth:** BetterAuth
- **Deployment:** Vercel

## Features

- Featured & popular recipes on the home page
- Recipe browsing with detailed views
- Search and filter through recipes
- User authentication for personalized experience
- Smooth animations and transitions
- Fully responsive design across devices
